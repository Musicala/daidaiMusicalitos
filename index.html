✏️ Crea tu propio juego de notas

Puedes corregir o crear ejercicios. Para la melodía de Dai Dai, compara siempre con el fragmento original.

Escribe DO, RE, MI, FA, SOL, LA, SI. Usa | para separar frases A, B, C... Usa - para un silencio. Para prolongar una nota: DO:2. También admite sostenidos, por ejemplo FA# o C#5.
